Work with me

I’m open to new projects. Here is what I take on, how we would work, and how to start.

I take on four kinds of work: backend and data systems that need to become reliable and easier to maintain, small focused tools and apps, forecasting and modelling with real-world data, and procedural images, short video and writing.

We start with a conversation about the problem, and before any code is written you get a one-page plan. I work in small, visible steps, so you always know where things stand. You work with me directly, and the project ends with documentation and a walkthrough, so it keeps running without me.

To get started, send me a few lines about what you are trying to do and what is in the way. A rough description is enough. I will reply with questions and, if it is a good fit, a plan.
